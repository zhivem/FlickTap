# 📁 Структура проекта FlickTap

## Описание папок

```
FlickTap-main/
├── src/                          # Исходный код приложения
│   ├── main/                     # Основной процесс Electron
│   │   └── config.js             # ⚙️ Конфигурация из переменных окружения
│   └── renderer/                 # Процесс рендеринга (UI)
│
├── config/                       # Конфигурационные файлы
├── assets/                       # Статические ресурсы (иконки, изображения)
│
├── main.js                       # 🚀 Точка входа Electron
├── preload.js                    # Безопасность - предварительная загрузка
├── renderer.js                   # Основная логика UI
├── index.html                    # HTML страница приложения
├── styles.css                    # Стили приложения
│
├── package.json                  # Зависимости проекта
├── .env                          # 🔐 Переменные окружения (не коммитить!)
├── .env.example                  # Шаблон для .env
└── .gitignore                    # Исключить файлы из Git
```

## 🔐 Управление API ключом

### Первый запуск:
1. Скопируйте `.env.example` в `.env`:
   ```bash
   cp .env.example .env
   ```

2. Отредактируйте `.env` и добавьте ваш API токен:
   ```
   API_TOKEN=ваш_токен_здесь
   API_BASE=https://api.bhcesh.me
   NODE_ENV=development
   ```

3. **ВАЖНО**: Не коммитьте `.env` на GitHub!
   - `.env` уже в `.gitignore` ✓

### Загрузка на GitHub:
- Загружайте только `.env.example`
- Каждый разработчик создает свой `.env` локально
- Никогда не делитесь реальными API ключами

## 🚀 Команды

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Запуск приложения
npm start

# Сборка установщика
npm run dist
```

✅ **Масштабируемость**: Легко добавлять новые модули в `src/`
