# FlickTap - смотреть фильмы онлайн на ПК

Десктопное приложение для просмотра каталога фильмов и сериалов с возможностью онлайн-просмотра.

> [!WARNING]  
В связи с ограничениями доступа к некоторым видеосервисам на территории России, для корректной работы видеоплееров может потребоваться использование VPN-соединения.

## 🎬 Возможности

- **📋 Каталог фильмов** - Просмотр фильмов, сериалов, мультфильмов и аниме
- **🔍 Поиск и фильтрация** - Поиск по названию, ID Кинопоиска, фильтрация по типу, качеству и году
- **🎥 Видеоплеер** - Качественный просмотр фильмов онлайн
- **📊 Детальная информация** - Полные сведения о фильмах, рейтинги, актерский состав
- **🎯 Умные функции** - Блокировка рекламы, франшизы фильмов, рейтинги Кинопоиск/IMDb
- **🖥️ Нативный интерфейс** - Кастомное оформление окон, темная тема

## 🚀 Быстрый старт

### Требования
- Node.js 14+
- npm или yarn
- Windows 10+ (для сборки)

### Установка

1. **Клонируйте репозиторий**
   ```bash
   git clone https://github.com/yourusername/FlickTap-main.git
   cd FlickTap-main
   ```

2. **Установите зависимости**
   ```bash
   npm install
   ```

3. **Настройте конфигурацию**
   ```bash
   cp .env.example .env
   ```
   Отредактируйте `.env` и добавьте ваш API токен:
   ```
   API_TOKEN=your_api_token_here
   API_BASE=https://api.bhcesh.me
   NODE_ENV=development
   ```

4. **Запустите приложение**
   ```bash
   npm start
   ```

## 🎮 Использование

### Основные функции:
- **Поиск** - Используйте поле поиска для быстрого нахождения фильмов
- **Фильтры** - Уточняйте поиск по типу контента, качеству и году
- **Просмотр** - Смотрите выбранные фильмы в встроенном плеере
- **Настройки** - Включите/выключите блокировку рекламы и другие параметры

### Горячие клавиши:
- `Esc` - Закрыть модальные окна
- Кнопки управления окном - Свернуть/развернуть/закрыть

## 🔐 Управление API ключом

Приложение использует переменные окружения для безопасного хранения API ключа:

1. **Локальная разработка**: Создайте `.env` из `.env.example`
2. **GitHub**: `.env` уже добавлен в `.gitignore` и не будет загружен
3. **CI/CD**: Установите переменные окружения в вашем CI провайдере

> **Важно**: Никогда не коммитьте файл `.env` с реальными ключами!

Приложение использует следующие API:

Все настройки хранятся локально в приложении и могут быть изменены через интерфейс.
